Unplugged Activity: Sort the City, No Labels

16 NYC street objects. No labels, no answer key, no instructions on how many groups to make.

Your task: click and drag each object below into groups that make sense to you. Make as many or as few groups as you want, and arrange them wherever helps you see your own groupings. There is no "correct" answer.

Sort them yourself

Drag the objects around. Cluster together whatever you think belongs together.

Compare to a real grouping

There isn't one right answer — here are three completely different, equally valid ways to group the exact same 16 objects. Watch the same cards rearrange themselves.

Discuss

How many groups did you make, and did that match how many groups showed up in the reveal? Did your neighbor group by something different — color, object type, or size? Is any one of these three groupings more "correct" than the others? What would change if you only looked at object type and ignored color entirely?

Connecting the activity to unsupervised learning

What happened in the activityMachine learning term
The 16 city objectsData (unlabeled)
Color, object type, sizeFeatures
No "correct" grouping was given to youNo labels — unsupervised learning
The groups you dragged togetherClusters
Deciding which objects "belong together"Similarity / distance between data points
Different people forming different groupingsDifferent features → different clustering results

This is exactly what an algorithm like k-means does mathematically: it groups data points by similarity, with no labels telling it what the "right" groups are. Which features you feed it changes what clusters it finds — just like grouping by color gave a different result than grouping by object type. Now imagine these 16 cards were actually 16 real NYC 311 complaint records instead — each one varying by borough, complaint type, and how many similar complaints came in that week. A clustering algorithm faces the exact same ambiguity you just did: there's no single "correct" way to group them, only different features that surface different patterns.
