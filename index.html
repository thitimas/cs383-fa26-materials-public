Learning Objectives

By the end of the semester, you'll be able to

  • Explain the ML workflow and the difference between supervised and unsupervised learning
  • Write vectorized NumPy code instead of slow Python loops
  • Query databases with SQL and manipulate DataFrames with Pandas — SELECT, WHERE, GROUP BY, joins
  • Handle datetimes, reshape data, and clean real-world data across multiple sources
  • Explore distributions, outliers, and correlation, and visualize findings with Matplotlib and Seaborn
  • Engineer features — scaling, encoding categoricals, avoiding data leakage
  • Build linear and logistic regression models with Ridge/Lasso regularization
  • Train classifiers and evaluate them with precision, recall, F1, and ROC/AUC
  • Use decision trees, random forests, and XGBoost, and interpret feature importance
  • Build scikit-learn pipelines with cross-validation and hyperparameter tuning
  • Apply k-Means clustering and PCA to find structure in unlabeled data
  • Train a neural network and apply transfer learning with Hugging Face
  • Run a bias audit and communicate fairness metrics in a model card
